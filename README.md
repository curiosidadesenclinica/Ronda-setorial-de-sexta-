# Ronda Setorial de Sexta

Projeto Cordova completo e descompactado para uso no GitHub ou no PC.

## Estrutura
- `www/index.html` — aplicativo completo da Ronda de Sexta
- `www/img/` — imagens do projeto
- `resources/icon.png` — ícone do aplicativo
- `resources/splash.png` — imagem reservada para tela de entrada
- `config.xml` — configuração Cordova/Android
- `package.json` — plugins e dependências
- `.github/workflows/gerar-apk.yml` — geração automática do APK

## Pastas criadas automaticamente
Não suba manualmente:
- `node_modules/`
- `plugins/`
- `platforms/`

## APK
O APK é gerado em:
`platforms/android/app/build/outputs/apk/debug/app-debug.apk`

E publicado pelo GitHub como:
`Ronda_Setorial_de_Sexta.apk`
